# Chat MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a working MVP codebase for a cross-platform chat app with NestJS API, PostgreSQL, Redis, Socket.IO, Docker deployment, and Flutter client source.

**Architecture:** The NestJS API owns authentication, contacts, conversations, messages, upload metadata, and realtime Socket.IO events. PostgreSQL is accessed through Prisma, Redis is reserved for online presence and future scaling, and Flutter calls HTTP APIs plus Socket.IO for realtime messages.

**Tech Stack:** Flutter, NestJS, TypeScript, Prisma, PostgreSQL, Redis, Socket.IO, Docker Compose, Nginx, Tencent Cloud COS placeholders.
